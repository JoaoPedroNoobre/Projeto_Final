**Proposta de Projeto – ConnectFlow**

Nosso grupo, composto por 4 integrantes, pretende desenvolver uma plataforma web de automação comercial com Inteligência Artificial, voltada para pequenos e médios negócios.

O objetivo é facilitar o atendimento ao cliente, automatizar tarefas e centralizar ferramentas em um único sistema.

A plataforma contará com **5 telas principais:**

1. **Dashboard:** painel com métricas de atendimentos, clientes, conversões e desempenho da IA.
2. **WhatsApp Integrado:** gerenciamento das conversas diretamente na plataforma, com atendimento automatizado por IA e possibilidade de intervenção humana.
3. **Agente de IA:** configuração de um assistente virtual capaz de responder dúvidas, consultar catálogos, informar preços e apresentar produtos ou serviços.
4. **Instagram Studio:** criação, edição e agendamento de publicações para atrair novos clientes.
5. **Configurações:** gerenciamento dos dados da empresa, redes sociais e integrações.

**Tecnologias previstas:** HTML, CSS, JavaScript, banco de dados, n8n para automações e APIs para integração com WhatsApp, Instagram e Inteligência Artificial.

O desenvolvimento será realizado de forma colaborativa pelos quatro integrantes, utilizando GitHub para organização do código, controle de versões e acompanhamento das contribuições.

**Nossa proposta é criar um sistema funcional, moderno e intuitivo, que ajude empresas a economizar tempo, melhorar o atendimento e transformar interações nas redes sociais em oportunidades de vendas.**
